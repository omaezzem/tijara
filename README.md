# Doz Takol 🎲

A Moroccan property-trading board game for 3–8 friends: on one screen, or online with each friend on their own phone.
Buy cities, collect rent in dirhams, build houses and hotels, and be the last one standing. English and Darija.

**Play:** https://omaezzem.github.io/tijara/

## Play online with friends

One player opens the game and taps **New game → Create room**, then shares the 5-letter code (or the copied link). The host picks the room size (3 to 8 players) and friends join with **Join room**. The host keeps the page open until the end of the game. Online play goes through a free public MQTT relay over secure WebSocket, so it works on any network (4G included) and no server of your own is needed.

## Play offline

Open `index.html` in any browser.
